# Scribebot 0.1

A local meeting recorder for Apple Silicon Macs, built for Hebrew conversations
with English technical terms.

## What's new

- A refreshed neutral interface, larger sidebar controls, and clearer transcripts.
- A regular Dock app that opens its main window at launch, plus a menu-bar shortcut.
- Consistent default column widths in Recordings and People; dividers remain
  draggable and keep their positions when switching sections.
- A Delete dialog offering audio only, transcript only, or both. Selected files
  move to macOS Trash. Transcript deletion includes its saved summary.
- A complete drag-to-Applications DMG with portable Python, whisper.cpp,
  the Hebrew model, and the technical glossary included.

## Install

Download **Scribebot-0.1-macOS-arm64.dmg**, open it, and drag Scribebot into
Applications. Requires **Apple Silicon and macOS 14.2+**. Grant system audio and
microphone permissions when requested. No Homebrew or source checkout is needed
for recording and transcription.

This build is **ad-hoc signed and not Apple-notarized**. If macOS blocks opening,
use Privacy & Security > Open Anyway only if you trust the download.
SHA256SUMS is provided for download integrity verification.

## Limitations

- Optional summaries require a separate local Ollama installation and gemma4:latest.
- No personal calendar index is bundled; People may initially be empty.
- Intel Macs are not supported by this asset.
- Microphone quality warnings are not yet surfaced by the recording UI.
- Multi-speaker diarization benchmarks use synthetic audio, not real meetings.

Existing recordings remain in Application Support when upgrading the app.
